游戏外部操作
前置说明：gameBinDir 必须设定，否则脚本无法找到游戏目录；游戏内启动方式见下方“游戏内部操作”
提示：可以直接下载本仓库源包（Source code zip）后解压使用
1. 移动游戏本体到本文件夹 GameBin 中
2. 按需编辑 config.json；如果不单独准备 config.json，脚本会在首次启动时提示你选择国服或外服模板，并自动复制生成 config.json
3. 点击 "点我.bat"
4. 需要的补丁目录由脚本按列表同步到 GameBin\game\Game\Content\Paks

配置规则
1. on：必须执行，失败就直接中断
2. auto：能执行就执行，不能执行就跳过
3. off：直接跳过
4. 文本文件先读内容，再决定是否写回覆盖；资源文件先比对哈希，再决定是否覆盖复制

game 开关说明
1. game：游戏启动（Game.exe）控制开关
   - on：必须启动游戏，失败则中断；Inject 和 Miku 也会启动
   - auto：尝试启动游戏，如果缺少文件则跳过；Inject 和 Miku 也会启动
   - off：禁用游戏启动，Inject 和 Miku 仍会启动
2. 默认值为 "on"，不配置时默认启动游戏

mikuGameArg 参数说明
1. mikuGameArg：MikuSB 启动参数控制
   - true：MikuSB 启动时加上 -game 参数
   - false：MikuSB 启动时不加 -game 参数
2. 此参数位于 launch 部分，默认值为 false

patch 说明
1. patch 是一个列表，每一项都是一个单键字典，key 是目录名，value 是同步方式
2. 支持的同步方式只有 hash 和 incremental
3. 示例：[{"GM_Patch":"hash"}, {"AntiHarmonyPatch":"hash"}, {"Common_Patch":"hash"}]

国服游戏内部操作
1. 先叉掉登录弹窗
2. 点击顶部 GM 按钮
3. 选择 功能->常用类->显示服务器列表
4. 点击右下角的执行
5. 点击右下角的服务器列表
6. 选择本地服务器
7. 127.0.0.1 后面的 5000 改成 21000
8. 点确定然后点新账号后可进入

Steam端游戏内部操作
1. 查看 MIKUSB 提供的账户密码
2. 使用该账户密码登录
3. 点击下方黑框选择服务器后进入
